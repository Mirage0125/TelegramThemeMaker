TELEGRAM THEME MAKER 3.9.0 — ИНСТРУКЦИЯ
======================================

Что изменилось в 3.9.0
----------------------
- При команде /start появляется первый экран с выбором Русский / English.
- Выбранный язык сохраняется в user_data\\languages.sqlite3 и не сбрасывается
  при перезапуске бота или обновлении проекта.
- Добавлена кнопка смены языка в главном меню.
- Переведены основные кнопки, редактор цветов, подсказки, каталог и инструкции экспорта.
- Приветствие и сообщения интерфейса стали короче и дружелюбнее.

Что изменилось в 3.8.0
----------------------
- Незавершённые сессии редактора теперь хранятся локально в SQLite и переживают
  перезапуск бота. База находится в user_data\fsm.sqlite3.
- Блокировка установки берётся до проверки и установки обновлений. Повторный
  запуск не сможет параллельно менять файлы программы.
- Автообновлятор сохраняет папку assets целиком, включая пользовательские файлы.
- Установочный ZIP не содержит папку assets: это защищает пользовательские картинки
  даже при первом обновлении со старой версии 3.7.3. Резервная обложка хранится отдельно
  в defaults\welcome.png; локальная assets\welcome.png всегда имеет приоритет.
- Добавлен Check-Install.bat: он проверяет файлы проекта, Python, библиотеки,
  конфигурацию, автозапуск, процесс бота и запускает регрессионные тесты.
- Добавлены автоматические тесты генераторов, хранения сессий, блокировки
  нескольких процессов и безопасного применения ZIP-обновлений.

Проверка установки
------------------
Запусти Check-Install.bat в папке проекта. Отчёт сохранится в logs\check-report.txt.
Скрипт не показывает токен BOT_TOKEN и не изменяет содержимое assets.
Он проверяет встроенную defaults\welcome.png; локальная assets\welcome.png необязательна.
Если проверка сообщает об отсутствующих библиотеках, запусти Start.bat и дождись
завершения установки зависимостей, затем повтори проверку.

----------------------

Сессии редактора теперь сохраняются в локальной базе user_data\fsm.sqlite3.

Создание темы
-------------
1. Нажми «Создать тему из фото» и отправь фотографию как фото или файл.
   Также можно вставить прямую публичную ссылку HTTP/HTTPS на JPG/PNG/WebP.
   Локальные/частные адреса и перенаправления на них блокируются; ограничение — 12 МБ.
2. Бот извлечёт палитру, сохранит изображение как обои и покажет макет чата.
3. При выборе «Основной цвет», «Акцент», «Мои сообщения» или «Входящие сообщения»
   появятся оттенки, найденные именно на загруженной фотографии. Выбери HEX-код.
4. Нажми «Перемешать цвета», чтобы получить другое сочетание из той же фотографии.
5. Кнопки прозрачности меняют то, насколько обои видны сквозь пузыри.
6. После настройки нажми «Экспортировать тему» и выбери платформу.

Значение цветов
----------------
Основной цвет — фон окон, списка чатов и панелей; картинка-обои задаётся отдельно.
Акцент — кнопки, ссылки, галочки, индикатор онлайн, выделение, значки файлов и другие активные элементы.
Мои сообщения — фон твоих исходящих пузырей.
Входящие сообщения — фон пузырей собеседников.
Прозрачность — сколько фоновых обоев видно через пузырь сообщений.

Форматы и ограничения
---------------------
Windows / Telegram Desktop:
  .tdesktop-theme — нативный формат темы Telegram Desktop.
  Без фото это текстовый файл цветовой схемы. С фото это ZIP-контейнер с
  colors.tdesktop-theme и background.jpg внутри. Telegram Desktop принимает
  оба варианта как тему.

Android / Telegram:
  .attheme — формат темы Android. Выбранные обои добавляются в файл через блок WPS.
  Разные версии Telegram могут по-разному отображать отдельные ключи.

iPhone / iOS:
  .tgios-theme — локальный формат темы Telegram iOS. В этой версии файл содержит
  палитру интерфейса; загруженная фотография в .tgios-theme не встраивается.

macOS / Telegram:
  .palette — нативный текстовый формат Telegram macOS с метаданными и записями
  key = value. Он не совместим с iOS YAML или Windows Desktop-палитрой и не включает
  локальную фотографию как обои.

Другие форматы:
  .tgx-theme — формат Telegram X для Android. Фото в этот файл не встраивается.
  .tdesktop-palette — палитра для импорта через редактор тем Telegram Desktop;
  это не самостоятельный файл темы для применения двойным щелчком.

Важно:
  Файлы разных клиентов Telegram не взаимозаменяемы. Предпросмотр в сообщении
  является макетом интерфейса, а не скриншотом реального Telegram. После экспорта
  нужно открыть файл в соответствующем официальном клиенте и проверить результат.
  Некоторые клиентские элементы могут игнорировать отдельные палитровые ключи.
  Облачную ссылку t.me/addtheme/... можно получить после публикации темы через
  официальный редактор от имени пользовательского аккаунта; обычный токен BotFather
  не публикует облачные темы.

Автозапуск на Windows
---------------------
1. Сначала выполни обычную первоначальную настройку: запусти Start.bat, вставь
   токен в .env и добейся успешного запуска бота. Это нужно сделать один раз.
2. Закрой обычный запуск бота (Ctrl+C в окне Start.bat).
3. Дважды щёлкни Install-Autostart.vbs. Скрипт создаст ярлык в папке автозагрузки
   текущего пользователя. Права администратора не нужны.
4. Скрипт сразу запустит бота в фоне. При следующих входах в Windows он будет
   запускаться автоматически; повторно открывать Start.bat не потребуется.
5. Журнал фонового запуска и ошибок находится в logs\bot.log. При превышении
   2 МБ предыдущий журнал сохраняется как logs\bot.previous.log.
6. Чтобы остановить уже работающий фоновый процесс, запусти Stop-Bot.vbs.
7. Для диагностики установки запусти Check-Install.bat; отчёт появится в logs\check-report.txt.
7. Чтобы отключить автозапуск, запусти Remove-Autostart.vbs. Остановка процесса
   и отключение автозапуска — отдельные действия.

Важно: это автозапуск после входа пользователя в Windows, а не запуск до экрана
входа. Компьютер должен быть включён, не спать и иметь доступ к интернету — иначе
бот будет недоступен в Telegram. Автозапуск не переносит бота на облачный сервер.

Запуск на Windows
-----------------
1. Распакуй архив.
2. Запусти Start.bat. Он НЕ скачивает и НЕ устанавливает Python.
   Он использует уже установленный Python 3.10–3.14. Если подходящего Python нет,
   скрипт остановится и покажет инструкцию по ручной установке.
3. Start.bat создаст .venv (если её ещё нет), проверит версию Python и установит
   библиотеки проекта. При повторном запуске pip не обновляется принудительно.
4. При первом запуске создастся .env и откроется Блокнот. Вставь токен после
   BOT_TOKEN=, сохрани файл и запусти Start.bat ещё раз.
5. Открой бота в Telegram и отправь /start.


Автоматические обновления через GitHub
--------------------------------------
- При запуске фоновой версии бот проверяет последний стабильный релиз в публичном
  репозитории Mirage0125/TelegramThemeMaker (не чаще одного раза в 6 часов).
- Если доступна новая версия, архив скачивается и сверяется с SHA-256. Только после
  успешной проверки файлы программы заменяются. При ошибке текущие файлы сохраняются.
- Файл .env, виртуальное окружение .venv, пользовательские изображения и база
  сессий в user_data, журналы logs, локальная папка assets и файл блокировки
  не заменяются и не удаляются.
- Если в релизе изменился requirements.txt, библиотеки обновляются внутри .venv.
- Команда /version показывает установленную версию и сообщает о проверке обновлений.
- Новая версия публикуется автоматически после изменения VERSION.txt и отправки коммита в main. GitHub Actions создаёт тег вида vX.Y.Z, собирает ZIP и SHA-256 и прикрепляет их к релизу.

Первое включение автообновлений требует один раз установить архив версии 3.7.1
поверх текущей папки проекта. Старый BackgroundRunner.py ещё не умеет проверять
GitHub, поэтому сам обновиться с 3.7.0 он не сможет. После этой замены следующие
опубликованные релизы будут устанавливаться автоматически при запуске.

Обновление существующего проекта
--------------------------------
1. Останови старого бота через Ctrl+C в его окне.
2. Распакуй новый архив поверх старой папки проекта, согласись на замену файлов.
3. НЕ удаляй и НЕ заменяй .env — в нём хранится токен.
4. Папку .venv можно оставить — Start.bat использует её и обновляет библиотеки.
5. Запусти Start.bat.

Безопасность
------------
- Не публикуй .env и токен бота.
- Если токен попал на скриншот или в публичный чат, отзови его через @BotFather
  командой /revoke и используй новый.
- Для остановки бота нажми Ctrl+C в окне запуска.


Версия 3.1.0 — расширенный Android и текстовые цвета
--------------------------------------------------
Android-экспорт теперь включает набор ключей из встроенной темы Telegram Android
(arctic.attheme) и дополнительные ключи совместимости. Ключи, которых нет в конкретной
версии клиента, Telegram обычно просто игнорирует.

В редакторе есть два отдельных пункта: «Основной текст интерфейса» и «Текст сообщений».
По умолчанию они выбираются автоматически как чёрный/белый, но ручное значение
сохраняется и не перезаписывается при экспорте.

Проверка на устройстве всё ещё нужна: версия Android-клиента может отличаться по
набору поддерживаемых ключей и поведению отдельных элементов.


Обновление 3.2.0
-----------------
Android: экспорт использует полный набор ключей из встроенной темы Telegram Android arctic.attheme и дополнительные известные legacy-ключи. Цвета списка чатов, статусов, ссылок, команд, цитат, аватаров, вкладок, файлов, голосовых элементов и мини-приложений связываются с основной палитрой. Основной текст и текст сообщений редактируются отдельно.
Windows: выделение сообщений стало контрастнее, значок реакции в списке чатов и цвета панели ответа используют акцент.
macOS: экспорт больше не использует синтаксис Windows Desktop palette. Реальный импорт на устройстве нужно проверить отдельно.

Дополнение версии 3.3.0
-----------------------
Android: расширены алиасы и правила для интерактивных синих/зелёных слотов,
команд, мини-приложений, выделения, текста сообщений и элементов профиля.
Windows: выбранные сообщения, ссылки, файлы, голосовые элементы и подписи
